What this audit found and fixed

  1. Section headings hid under the sticky header when you used the landing page links. They now stop below it.
  2. "CreoStart, for / your first projects" wrapped awkwardly because its container was too narrow.
  3. The marketplace subtitle claimed "verified" and "milestone-funded" contracts. Neither is true yet, so it now just describes the projects.
  4. "Resend link" showed the anonymous wording ("If this email is registered…") to people who are signed in. It now names the address the link went to.
  5. The verify-email error page said "request a new one" twice. The second line now explains how links work.
  6. Red outlines stayed on the reset form after you corrected the field.
  7. Tier requirements read like a database ("Need avg rating ≥ 4 (have 0.0)"), which also contradicted "no history counts as neutral". They're now plain sentences, for example "Reach an average rating of 4.0 or higher (no reviews yet)".
  8. The rights checkbox didn't turn red when it was the reason a save failed.
  9. Client profiles said "Clients compare evidence", which is wrong when you're the client.
  10. Notices touched the email field in the log-in dialog.
  11. "You've been signed out" used the red danger style. It's neutral blue now; red is kept for suspensions.
  12. Unknown addresses showed a bare "Cannot GET" page. They now show a branded 404 page, and a test covers it.

Security

  • Public profiles return only allow-listed fields. KYC status and earnings are never included (checked live and covered by tests).
  • Sessions are stored on the server, so logout, password reset and suspension take effect immediately.
  • Login takes the same time and gives the same error whether or not an email exists, and the strict rate limit applies only to login-type requests.
  • Links you add must be http or https, so javascript: links are rejected.
  • Payments are switched off. A clearly labelled sandbox mode exists for development and can't be enabled in production.
